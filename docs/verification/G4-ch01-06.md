## Proposed VERIFIED_FACTS additions

| Topic | Proposed statement |
|---|---|
| DCGM profiling-field names | DCGM 4.6.0+ renames `DCGM_FI_PROF_GR_ENGINE_ACTIVE`→`DCGM_FI_PROF_GR_ENGINE_UTIL_RATIO` (1001), `SM_ACTIVE`→`SM_UTIL_RATIO` (1002), `SM_OCCUPANCY`→`SM_OCCUPANCY_RATIO` (1003), `PIPE_TENSOR_ACTIVE`→`TENSOR_UTIL_RATIO` (1004), `DRAM_ACTIVE`→`DRAM_UTIL_RATIO` (1005), `PIPE_FP64/FP32/FP16_ACTIVE`→`FP64/FP32/FP16_UTIL_RATIO` (1006–1008). Old names remain aliases with the same IDs. `PCIE_TX/RX_BYTES` (1009/1010) and `NVLINK_TX/RX_BYTES` (1011/1012) are unchanged. Source: NVIDIA/DCGM `dcgmlib/dcgm_fields.h` at v4.5.3 vs v4.6.1 vs v4.7.0. |
| DCGM GPU util | DCGM 4.7.0 deprecates `DCGM_FI_DEV_GPU_UTIL` (203, percent) in favour of `DCGM_FI_DEV_GPU_UTIL_RATIO` (1613, 0–1). Also renamed in 4.6+/4.7: `DCGM_FI_DEV_GPU_TEMP`→`_GPU_TEMP_CELSIUS` (150), `DCGM_FI_DEV_POWER_USAGE`→`_BOARD_POWER_WATTS` (155), `DCGM_FI_DEV_PCIE_REPLAY_COUNTER`→`_PCIE_REPLAY_TOTAL` (202), `DCGM_FI_DEV_XID_ERRORS`→`_XID_ERROR` (230). |
| DCGM violation counters | `DCGM_FI_DEV_POWER_VIOLATION` (240) / `THERMAL_VIOLATION` (241): DCGM 3.x documents µs, 4.x headers document ns; deprecated in 4.7 for `DCGM_FI_DEV_GPU_POWER/THERMAL_THROTTLE_SECONDS_TOTAL` (1617/1618). |
| NCCL P2P channel lines | Intra-node P2P lines read `via P2P/CUMEM` (NCCL ≥ 2.19 with cuMem auto-enabled), `via P2P/IPC` (cuMem off / older), `via P2P/direct pointer` (same process); suffixes `/read`, `/CE`; `P2P/MNNVL` on multi-node NVLink. Source: `src/transport/p2p.cc`. |
| lspci link annotations | pciutils 3.6–3.7 print `(ok)`/`(downgraded)`; 3.8+ print only `(downgraded)` or `(overdriven)` and nothing when healthy (also suppressed for downstream ports). |
| nvidia-smi version field | nvidia-smi v590 deprecates "Driver Version"/"CUDA Version" in `-q` output in favour of "KMD Version"/"CUDA UMD Version". |
| cpufreq powersave | `powersave` is dynamic only with active-mode `intel_pstate` and `amd-pstate-epp`; with `acpi-cpufreq`, `intel_cpufreq` (intel_pstate passive) or `amd-pstate` (passive/guided) it pins minimum frequency. |

## Cross-scope issues (not fixed)

- Any chapter outside 01–06 that uses `DCGM_FI_PROF_*_ACTIVE`, `DCGM_FI_DEV_GPU_UTIL`, `DCGM_FI_DEV_GPU_TEMP`, `DCGM_FI_DEV_POWER_USAGE`, `DCGM_FI_DEV_XID_ERRORS` or `DCGM_FI_DEV_PCIE_REPLAY_COUNTER` (notably ch18 dashboards and ch19 fault taxonomy, plus capstones) should carry the DCGM 4.6+/4.7 rename note above. dcgm-exporter metric names in Prometheus follow the field names, so dashboards should also check which name their exporter version emits.
- Chapters quoting NCCL intra-node channel lines `via P2P/IPC` (likely ch08, ch12, ch13) should use `P2P/CUMEM` for NCCL ≥ 2.19 or add the version note.
- Any chapter or lab parser that expects `(ok)` in `lspci` output should treat it as optional (pciutils ≥ 3.8 omits it).
