## 3. Collection, screen and deduplication

- **Selection.** Same title filter and purposive hand-pick as 2026-10. Every 2026-10 requisition still listed
  was kept and re-read. The 13 new requisitions were chosen to add a second location for existing roles
  (which tests the dedupe), more AI-network variety (front-end, storage fabric, datapath observability), fleet
  operations, physical-network/cabling, an inference-platform role and a hardware fabric-health role.
- **Scope screen: 7 excluded.**
  - OpenAI "Network Engineer" (San Francisco and London): enterprise networking. Also excluded in 2026-10.
  - Crusoe "Senior Staff Optics Engineer, Network Qualification & Strategy": WAN/long-haul optical. Also
    excluded in 2026-10.
  - OpenAI "Network Infrastructure Engineer, Global Network Infra (WAN)": WAN/backbone.
  - Graphcore "Senior Network Operations Engineer": corporate IT networking (campus Wi-Fi, firewalls, SD-WAN).
  - NVIDIA "Network Site Reliability Engineer": the Enterprise Network Support and SRE team, covering campus
    and data-centre networks.
  - NVIDIA "Senior Network Engineer - DGX Cloud": a network for internal software-development workflows
    (Corp IT, peering, WAN).

  CoreWeave "Senior Optical Network Engineer II", excluded in 2026-10, has closed.
- **Dedupe rule `ch24-role-v1`**, unchanged. The posting-level rule finds 0 duplicates in 60 rows. The role
  rule removes **10 rows across 9 roles**:

- **Seniority** comes from the title only. "Sr." is read as senior. Numeric grades ("II", "III") are not mapped
  to a level.
- **Not recorded:** salaries (deliberately), applicant counts, and anything beyond public posting text.

## 6. Limitations

All 2026-10 limitations still apply ([G7-ch24.md](G7-ch24.md) §5): a purposive sample, no hyperscaler, thin
vendor coverage, heavy US weighting, author-paraphrased tags, and a one-day window. In addition:

- **One week apart.** The two snapshots are 7 days apart and share 47 requisitions, so they are not independent
  samples. Count changes mostly reflect the 13 added requisitions, 3 closures, posting edits and tag
  corrections (section 4), not market movement.
- **Larger sample, same route.** The new rows came from the same 11 boards. Lambda (9 roles) and Nscale (7) are
  still over-represented.
- **Re-tagging.** Re-reading against current text fixed some omissions in the 2026-10 tags. The 2026-10 files
  were not edited, so their counts stand as published for that snapshot.
