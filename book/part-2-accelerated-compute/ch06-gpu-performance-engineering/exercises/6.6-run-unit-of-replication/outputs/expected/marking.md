# Marking scheme: 6.6 The run is the unit of replication

Type knowledge-check · kind written · tier L1 · 3 points

**Evidence required:** correlation argument and consequence.

| Criterion | Points |
|---|---|
| Iterations within one process share allocations, clocks, kernel selection, placement and thermal state, so they are positively correlated | 1 |
| A CI from 300 iterations of one run reflects within-run noise only and ignores run-to-run variation | 1 |
| Consequence: the interval is far too narrow, producing false positives | 1 |
