# Marking scheme: 6.5 Sources of run-to-run variation

Type knowledge-check · kind written · tier L1 · 5 points

**Evidence required:** five source–control pairs.

| Criterion | Points |
|---|---|
| Warm-up/caching effects paired with discarding a fixed number of iterations | 1 |
| Clocks, power and thermal state paired with locked clocks or recorded clocks_event_reasons and exclusion rules | 1 |
| Contention from other processes paired with a dedicated GPU and a check of compute apps | 1 |
| Software version drift paired with a manifest and a pinned container digest | 1 |
| A fifth valid pair (time drift/interleaving, input size, CPU frequency/affinity, timing method with CUDA events) | 1 |
