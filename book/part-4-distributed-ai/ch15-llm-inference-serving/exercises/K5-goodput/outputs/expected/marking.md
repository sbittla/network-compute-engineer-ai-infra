# Marking scheme: K5 Goodput

Type knowledge-check · kind written · tier L1 · 4 points

**Evidence required:** both definitions and a concrete scenario

| Criterion | Points |
|---|---|
| DistServe definition: maximum request rate at which a target fraction meets both TTFT and TPOT SLOs | 1 |
| Operational definition: SLO-meeting requests per second on a trace | 1 |
| Concrete scenario where throughput rises while goodput falls, with numbers | 2 |
