# Marking scheme: 13.9 Trace a communication path (O1)

Type outline-mandated · kind written · tier L1 · 10 points

**Evidence required:** two or three captioned diagrams, a copy/crossing count per variant, and the canonical leaf/spine names used

| Criterion | Points |
|---|---|
| GDR same-rail diagram: every hop annotated with bandwidth class and labelled illustrative latency | 3 |
| Host-staged diagram with pinned host buffers in socket 1 DRAM | 2 |
| Copy/crossing counts per variant: GDR 0 copies, 2 PCIe, 1 hop; host-staged 2 copies, 4 PCIe | 2 |
| Cross-rail variant: leaf r6, orion-be-spine-S, leaf r2 (3 hops) or PXN NVLink hop then rail 2 | 2 |
| Canonical leaf/spine names and evidence labels used throughout | 1 |
