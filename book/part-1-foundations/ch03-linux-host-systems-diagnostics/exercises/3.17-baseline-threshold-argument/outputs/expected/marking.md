# Marking scheme: 3.17 Arguing a baseline threshold

Type reflection · kind written · tier L1 · 3 points

**Evidence required:** Both arguments and a data requirement.

| Criterion | Points |
|---|---|
| An argument for a tighter value of a named threshold | 1 |
| An argument for a looser value of the same threshold | 1 |
| The fleet data needed to set it from evidence (distribution over weeks, correlated with later failures or RMA outcomes, acceptable false-positive rate) | 1 |
