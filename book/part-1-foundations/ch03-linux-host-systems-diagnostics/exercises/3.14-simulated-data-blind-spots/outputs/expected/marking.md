# Marking scheme: 3.14 What simulated snapshots cannot reveal

Type reflection · kind written · tier L1 · 3 points

**Evidence required:** Three items, each with a validation step.

| Criterion | Points |
|---|---|
| First real-host failure mode with a validation step (for example tool output format differences, validated on real captures per OS image) | 1 |
| Second failure mode with a validation step (for example intermittent faults missed by one snapshot, validated by repeated collection and continuous metrics) | 1 |
| Third failure mode with a validation step (for example thresholds or naming that do not match the real fleet, validated by fleet distributions or a known-good baseline) | 1 |
