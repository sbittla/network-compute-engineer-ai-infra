# Marking scheme: 3.2 Since-boot samples

Type knowledge-check · kind written · tier L1 · 3 points

**Evidence required:** A definition of what the first sample measures, plus a numeric example.

| Criterion | Points |
|---|---|
| The first vmstat line and the first iostat report are averages over the whole time since boot | 1 |
| A numeric example in which the since-boot sample hides or dilutes a live problem | 1 |
| The example shows the arithmetic (for example b = 0 since boot vs 15 live; averaging gives 12) | 1 |
