# Marking scheme: K1 Five properties of an AI training cluster

Type knowledge-check · kind written · tier L1 · 4 points

**Evidence required:** Five distinguishing properties, each with an ORION number.

| Criterion | Points |
|---|---|
| Five distinct properties named (coupling, bandwidth per server, traffic pattern, power density, failure semantics, or goodput economics) | 2 |
| Each property carries a correct ORION number (for example 17.4 s step, 3.2 Tb/s backend, about 41 kW per rack, 48 h job MTBF) | 1 |
| The contrast with a conventional cloud fleet is stated for each property | 1 |
