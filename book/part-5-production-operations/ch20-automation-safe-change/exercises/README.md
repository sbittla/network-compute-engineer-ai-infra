# Chapter 20 — Exercise folders

One folder per exercise in [`../exercises.md`](../exercises.md). Each folder holds the prompt (copied
verbatim), what to submit, and an empty `outputs/` for your evidence. Knowledge-check items of Section 20.1
and reflection items of Section 20.11 are separate folders because they are marked separately.
Kinds: `computed` = numeric or algorithmic answer with a reference script; `lab` = completed through Lab 20
and graded by the named checker lines; `written` = reasoning, design, or reflection.
