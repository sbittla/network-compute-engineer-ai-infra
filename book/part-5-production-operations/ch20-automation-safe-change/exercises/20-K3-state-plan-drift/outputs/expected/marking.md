# Marking scheme: 20-K3 IaC state, plan and drift

Type knowledge-check · kind written · tier L1 · 4 points

**Evidence required:** Written answer (2–5 sentences) that names the mechanism, not just the term.

| Criterion | Points |
|---|---|
| State defined as the tool's record of managed objects and last-known attributes | 1 |
| Plan defined as the computed diff (create/update/replace/destroy) | 1 |
| Drift defined as real state differing from declared/recorded state | 1 |
| Destroy or forced replace of a fabric object flagged as an outage, with saved-plan apply | 1 |
