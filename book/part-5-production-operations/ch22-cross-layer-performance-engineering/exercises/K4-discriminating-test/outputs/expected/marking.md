# Marking scheme: K4 Discriminating test: definition and examples

Type knowledge-check · kind written · tier L1 · 4 points

**Evidence required:** definition; the example with each hypothesis's predicted outcome; why the non-example fails.

| Criterion | Points |
|---|---|
| Definition: competing hypotheses predict different outcomes | 1 |
| Example partition (TP span) with H-placement predicting a large gap | 1 |
| H-network's prediction for the same test (uniform slowdown of multi-node jobs, no gap aligned with TP span) | 1 |
| Non-example explained: every hypothesis predicts something odd on it | 1 |
