# Marking scheme: K2 Row-remapper states

Type knowledge-check · kind written · tier L1 · 6 points

**Evidence required:** three actions with a one-line mechanism each

| Criterion | Points |
|---|---|
| (a) Pending: drain when free, reset, verify pending cleared, diagnostics, return; mechanism: remap active only after reset | 2 |
| (b) Remapping failure: quarantine and RMA; mechanism: no spare row in the bank | 2 |
| (c) Remapped, nothing pending: healthy, monitor only; does not treat it as a fault | 2 |
