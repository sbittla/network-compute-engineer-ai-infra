# Marking scheme: K6 Domain vs unit

Type knowledge-check · kind written · tier L1 · 5 points

**Evidence required:** both definitions applied; one coinciding case

| Criterion | Points |
|---|---|
| Fault domain applied: the mlx5_3 link (HCA port, optic, cable) | 2 |
| Scheduling unit applied: the whole node, because a TP = 8 rail-optimized job needs all 8 rails | 2 |
| One valid coinciding case (job using only part of a node, or a fault domain that is itself the node) | 1 |
