# Marking scheme: R4 Waive, reflash, or fast-track a bundle?

Type reflection · kind written · tier L1 · 5 points

**Evidence required:** A decision; the evidence and approval path for it.

| Criterion | Points |
|---|---|
| Clear decision (not a silent waiver) | 2 |
| Evidence required for the chosen path (release notes, own reproduction of bug and fix, pilot acceptance) | 2 |
| Approval path / risk owner / expiry | 1 |
