# Marking scheme: R1 Deriving real acceptance thresholds

Type reflection · kind written · tier L1 · 5 points

**Evidence required:** A procedure naming repetitions, statistic (e.g., median and spread), and margin.

| Criterion | Points |
|---|---|
| Known-good population size and repetitions per node after warm-up stated | 2 |
| Robust statistic named (median with IQR or percentile) | 2 |
| Margin rule for FAIL/WARN and re-baselining per bundle; labels result MEASURED | 1 |
