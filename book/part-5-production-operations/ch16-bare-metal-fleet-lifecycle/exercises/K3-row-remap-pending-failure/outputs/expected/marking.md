# Marking scheme: K3 Pending row remap versus remapping failure

Type knowledge-check · kind written · tier L1 · 5 points

**Evidence required:** Definitions; one action each; which one is an RMA candidate.

| Criterion | Points |
|---|---|
| Defines pending remap: failing HBM row recorded, remap takes effect only after GPU reset | 2 |
| Defines remapping failure (spares exhausted / remap failed) and identifies it as the RMA candidate | 2 |
| One correct operational action for each (drain + reset + verify + DCGM -r 3; drain + RMA with evidence) | 1 |
