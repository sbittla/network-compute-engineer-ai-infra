# Marking scheme: 7.K1 Point-to-point /31 addressing

Type knowledge-check · kind computed · tier L1 · 4 points

**Evidence required:** RFC numbers, both address counts with arithmetic, one operational reason.

| Criterion | Points |
|---|---|
| RFC 3021 named as the source permitting /31 on point-to-point links | 1 |
| RFC 6164 and the /127 IPv6 prefix length named | 1 |
| Both counts correct with arithmetic: 512 × 2 = 1,024 (/31) and 512 × 4 = 2,048 (/30) | 1 |
| An operational (not address-conservation) reason, e.g. addresses computable from link index | 1 |
