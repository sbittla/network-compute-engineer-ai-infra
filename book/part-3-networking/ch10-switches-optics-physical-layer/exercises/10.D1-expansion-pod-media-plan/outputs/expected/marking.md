# Marking scheme: 10.D1 Media plan for ORION's expansion pod

Type design-challenge · kind written · tier L1 · 10 points

**Evidence required:** a decision table (link class × medium × reason), an optics-power estimate with stated per-module power, and the spare-part list implied by your choices.

| Criterion | Points |
|---|---|
| Decision table covering host links, leaf–spine, cross-hall and module form factor, each defended on reach, power, failure modes and cleaning | 4 |
| Quantitative optics-power estimate with stated per-module power | 2 |
| Spare-part list consistent with the choices | 2 |
| Vendor verification list (supported optics per NOS release, AEC power, FEC mode, twin-port availability) | 2 |
