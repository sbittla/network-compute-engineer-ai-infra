# Marking scheme: 10.R2 Setting real warning thresholds

Type reflection · kind written · tier L1 · 4 points

**Evidence required:** ≤ 150 words naming the data sources (commissioning baselines, vendor thresholds, failure history).

| Criterion | Points |
|---|---|
| Uses commissioning baselines per optic type and link class (distribution, not one value) | 1 |
| Uses vendor module thresholds and the KP4 limit as outer bounds | 1 |
| Refines with failure/RMA history (which trends preceded failures) | 1 |
| States a concrete rule (e.g. ≥ 1 decade below the FEC limit) and keeps `[ILLUSTRATIVE]` until validated | 1 |
