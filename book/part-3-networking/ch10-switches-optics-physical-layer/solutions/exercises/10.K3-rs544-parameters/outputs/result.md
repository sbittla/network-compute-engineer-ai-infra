# 10.K3 — RS(544,514) parameters `[MODELED]`

| Parameter | Working | Value |
|---|---|---|
| Symbol size | GF(2^10) | 10 bits |
| Symbols per codeword | n | 544 |
| Parity symbols | n - k = 544 - 514 = 30 | 30 |
| Correctable symbols | t = (n - k) / 2 = 30 / 2 = 15 | 15 |
| Codeword size | n x m = 544 x 10 = 5440 | 5,440 bits |

A codeword with 16 or more bad symbols is uncorrectable.
