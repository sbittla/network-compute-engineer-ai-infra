# Marking scheme: 8.6 Reading ibstat

Type knowledge-check · kind written · tier L1 · 4 points

**Evidence required:** correct component for each; a real command for each.

| Criterion | Points |
|---|---|
| Initializing/LinkUp/LID 0 → subnet manager has not configured the port | 1 |
| A real first command for it (sminfo, or SM logs / ibstat SM lid comparison) | 1 |
| Down/Polling → no link partner: cable, transceiver or remote switch port | 1 |
| A real first command for it (iblinkinfo / ibnetdiscover from the fabric side, then physical inspection) | 1 |
