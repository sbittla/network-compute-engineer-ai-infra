# Marking scheme: 8.10 Draw the TCP and RDMA data paths

Type outline-mandated · kind written · tier L1 · 10 points

**Evidence required:** two labelled diagrams (Mermaid or hand-drawn); a count table per side; offload discussion.

| Criterion | Points |
|---|---|
| Two labelled diagrams showing kernel and remote-CPU involvement | 4 |
| Count table per side: CPU copies, DMA transfers, system calls, interrupts, context switches | 4 |
| Offload discussion: what TSO/GRO/interrupt moderation/MSG_ZEROCOPY change and what they cannot remove | 2 |
