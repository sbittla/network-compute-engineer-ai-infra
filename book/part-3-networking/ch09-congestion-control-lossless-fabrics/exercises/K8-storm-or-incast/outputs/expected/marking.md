# Marking scheme: K8 PFC storm or incast?

Type knowledge-check · kind written · tier L1 · 4 points

**Evidence required:** four signals with the expected value for each case.

| Criterion | Points |
|---|---|
| Signal 1 with both expected values (e.g. queue flat at max vs deep but varying) | 1 |
| Signal 2 with both values (e.g. egress ≈ 0 vs ≈ line rate) | 1 |
| Signal 3 with both values (e.g. ECN marks ≈ 0 vs heavy) | 1 |
| Signal 4 with both values (e.g. pause received from the device sustained vs ≈ 0; device rx throughput) | 1 |
