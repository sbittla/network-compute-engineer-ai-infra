# Marking scheme: K1 Roles by what they are paged for

Type knowledge-check · kind written · tier L1 · 8 points

**Evidence required:** six rows: role, incident, first evidence (command, counter or log).

| Criterion | Points |
|---|---|
| AI Network and GPU/HPC rows: plausible page and a real first-evidence source | 2 |
| Cluster/Platform and Performance rows; performance framed as an owned investigation, not a page | 2 |
| SRE/Operations and Network Hardware/Vendor rows with plausible incident and evidence | 2 |
| Evidence is specific (named command or counter class), no invented flags | 2 |
