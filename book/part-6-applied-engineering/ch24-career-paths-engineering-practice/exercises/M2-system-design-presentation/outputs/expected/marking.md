# Marking scheme: M2 System-design interview presentation

Type outline-mandated · kind written · tier L1 · 20 points

**Evidence required:** assumptions table with labels; all capacity arithmetic; at least one data-path diagram; failure-domain table; day-one validation plan; answers to two follow-ups you anticipate; rehearsal time.

| Criterion | Points |
|---|---|
| Assumptions table with evidence labels; complete capacity arithmetic propagated from the changed constraint | 8 |
| At least one data-path diagram | 3 |
| Failure-domain table with detection | 3 |
| Day-one validation plan | 2 |
| Two anticipated follow-ups answered and rehearsal within 18–22 min | 4 |
