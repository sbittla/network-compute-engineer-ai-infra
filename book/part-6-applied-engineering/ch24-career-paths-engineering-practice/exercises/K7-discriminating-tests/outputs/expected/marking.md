# Marking scheme: K7 Discriminating tests

Type knowledge-check · kind written · tier L1 · 4 points

**Evidence required:** definition; the test; both possible outcomes and what each implies.

| Criterion | Points |
|---|---|
| Definition: competing hypotheses predict different outcomes, so the result eliminates at least one | 1 |
| Names the test: per-port FEC/CRC counters and optic Rx power on the rail-3 links | 1 |
| Both outcomes: isolated errors + low Rx power → physical; pauses/ECN on many ports with clean FEC/CRC → congestion | 2 |
