# Marking scheme: K2 Why every assumption needs an owner and a validation

Type knowledge-check · kind written · tier L1 · 4 points

**Evidence required:** one failure mode for each field

| Criterion | Points |
|---|---|
| Owner: failure mode named (nobody validates it, nobody is paged, it silently becomes fact) | 2 |
| Validation: failure mode named (assumption is unfalsifiable; belief indistinguishable from measurement) | 1 |
| Recognizes 'Validation: TBD' as the classic symptom; answer is about accountability and falsifiability, not documentation | 1 |
