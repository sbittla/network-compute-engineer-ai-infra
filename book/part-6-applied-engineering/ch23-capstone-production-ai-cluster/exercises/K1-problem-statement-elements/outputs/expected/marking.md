# Marking scheme: K1 Five elements of a capstone problem statement

Type knowledge-check · kind written · tier L1 · 5 points

**Evidence required:** five elements, five checkable consequences

| Criterion | Points |
|---|---|
| Workload named, with the consequence that FLOPs, memory and communication can be recomputed | 1 |
| Numeric objective named, with the consequence that required throughput and margin can be checked | 1 |
| Constraints named, with a power/space/budget invariant a reviewer can check | 1 |
| Scope boundary named, with the consequence that out-of-scope interfaces must be specified | 1 |
| Evidence tier named, with the consequence of which numbers may be labelled MEASURED | 1 |
